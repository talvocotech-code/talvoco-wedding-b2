# Talvoco UK wedding invitation template B2 - demo with fictional names, dates and venues

- Live demo: https://talvoco-wedding-b2.vercel.app/
- Built with Vite. Run locally: `npm install && npm run dev`; production build: `npm run build`
- Demo contact values (couple, WhatsApp number, date) live at the top of `public/js/main.js`: replace per customer.
- Crafted by [Talvoco](https://talvoco.com)
- Music: "Peaceful Desolation" by Kevin MacLeod (incompetech.com), CC BY 4.0. See MUSIC-LICENSES.md.
